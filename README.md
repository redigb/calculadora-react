# Calculator

A functional calculator built with React, designed for both basic and advanced calculations with an intuitive interface.

## Features

- **Basic Operations**: Perform addition, subtraction, multiplication, and division seamlessly.
- **Advanced Functions**: Calculate percentages (`%`), square roots (`√`), and use parentheses for complex expressions.
- **Memory Management**: Add (`M+`) or subtract (`M-`) values to memory, recall (`MR`), or clear (`MC`).
- **History**: Displays the last 3 calculations for quick reference.
- **Keyboard Interaction**: Use numeric keys (0-9), operators (+, -, *, /), Enter (=), Backspace (⌫), and Escape (C) to operate without a mouse.
- **Flexible Clearing**: Clear everything with `C` or delete the last character with `⌫`.
