# Calculator

## Características

- **Operaciones básicas**: Realiza suma, resta, multiplicación y división de manera sencilla.
- **Funciones avanzadas**: Calcula porcentajes (`%`), raíces cuadradas (`√`), y permite el uso de paréntesis para operaciones complejas.
- **Gestión de memoria**: Agrega (`M+`) o resta (`M-`) valores a la memoria, recuérdala (`MR`) o límpiala (`MC`).
- **Historial**: Muestra los últimos 3 cálculos realizados para referencia rápida.
- **Interacción con teclado**: Usa teclas numéricas (0-9), operadores (+, -, *, /), Enter (=), Backspace (⌫), y Escape (C) para operar sin ratón.
- **Borrado flexible**: Limpia todo con `C` o elimina el último carácter con `⌫`.

## Instalación

1. Asegúrate de tener **Node.js** y **npm** instalados.
2. Clona el repositorio:
   ```bash
   git clone https://github.com/redigb/calculadora-react.git
   ```
3. Navega al directorio:
   ```bash
   cd calculadora-react
   ```
4. Instala las dependencias:
   ```bash
   npm install
   ```
5. Inicia la aplicación:
   ```bash
   npm run dev
   ```
6. Abre tu navegador en la URL proporcionada (normalmente `http://localhost:5173`).

## Uso

- **Clic en botones**: Selecciona números y operadores con un clic.
- **Teclado**: Opera con teclas numéricas y comandos especiales.
- **Funciones especiales**: Aprovecha `C` para reiniciar, `⌫` para corregir, `%` y `√` para cálculos avanzados, paréntesis para expresiones, y memoria para guardar valores.

## Tecnologías Utilizadas

- **React**: Para la interfaz de usuario.
- **Vite**: Herramienta de construcción.
- **CSS**: Estilizado.
- **JavaScript**: Lógica de cálculo.
